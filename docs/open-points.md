# Open points

Raised while agreeing the skeleton for CAAS-1374 (2026-09-30). Each needs an owner and a decision.

| # | Open point | Why it matters | Blocks |
|---|---|---|---|
| 1 | **Login mode: who creates the demo users?** The pipeline only inserts the short-lived CI user. Nothing creates accounts for real people. Candidate: a `create-user` job like the passcode job | A login-mode prototype deploys with nobody able to log in. Until this is resolved the template defaults to `protection: passcode` | Login mode in real use |
| 2 | **CAAS-1373 contradicts itself** (single-writer path check, CAAS-1400). The state block in `docs/backlog.md` is "written only by the method skill", but "a PR that changes the state block fails the build". The method skill's own writes also go through a PR plus auto-merge | The path check can't be built as written. Its locked-path part is built (`config/gates/path_check.py`); the backlog-ID part waits for this (`TODO(CAAS-1390)` in `path-check.yml`) | CAAS-1400, CAAS-1390 |
| 3 | ~~Real design-token export~~ **Resolved 2026-10-01.** `design-tokens/tokens.json` is exported from the 3ap Design System (Figma) by a script the template maintainers keep outside this repo (the design system has no Figma Variables, so the script reads swatches, text styles and the spacing table). See `design-tokens/EXPORTED_FROM.md` | Replace the script with a Variables export once the designers add Variables. Who keeps the script, and where, is not written down yet | Template maintainers |
| 4 | **UI styling approach.** The walking skeleton builds `ui/` on MUI, used only inside `ui/` (features import from `@/ui`, enforced by lint), themed from the tokens (`ui/theme.ts`): the Figma "Elements" page is a Material Design sticker sheet. To confirm with the designer. The Spring-rendered `/gate` and `/login` pages are styled from the same tokens with the same choices (`platform/web/EntryPage`, `backend/src/main/resources/platform/entry-page.css`); the designer confirms those too | Everything behind `@/ui`, and the look of `/gate` and `/login` | Confirmation by the designer |
